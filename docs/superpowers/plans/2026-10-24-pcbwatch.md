# pcbwatch implementation plan

Spec: `docs/superpowers/specs/2026-10-24-pcbwatch-design.md`

1. **Probe kicad-cli 9.0.2** (done before writing code): sheet naming and
   order for hierarchical schematics, board export flags, exit codes on
   corrupt files. Finding: corrupt schematic exits 0 -> detect by output.
2. **`pcbwatch.py` backend**: `discover`, `resolve`, `View`/`Watch`/`Watcher`
   (poll, debounce, export into temp dir, keep last good render), config in
   `~/.pcbwatch.json` (overridable by `PCBWATCH_CONFIG` for tests).
3. **HTTP API** on 127.0.0.1: `GET /`, `/api/state`, `/api/projects`,
   `/svg?w=&v=`; `POST /api/watch`, `/api/unwatch`, `/api/rescan`
   (same-origin only).
4. **Page** (inline in the file): sidebar, viewer with pan/zoom/fit,
   picker with filter + paste-a-path, follow toggle.
5. **`test_pcbwatch.py`**: end-to-end against a running server and a copy
   of a KiCad template project:
   - watch -> sheet and board views appear with SVG content
   - edit schematic -> its version increments, board version does not
   - corrupt schematic -> error reported, last SVG still served
   - corrupt board -> error reported
   - repair -> errors clear
   - unwatch -> gone; config file written to the override path
   - cross-origin POST -> 403
6. **Visual check** in Chrome: picker, schematic, board, a live edit
   appearing.
7. **README** with usage.

## Iteration 2: selectable board layers

8. Probe `--mode-multi` (done): alignment, naming, timing, empty layers.
9. Backend: parse layer list from the board; export all layers in one call;
   board becomes a set of per-layer views (content-hashed individually);
   `/svg?…&layer=` serves one layer; state lists layers with colour, empty
   flag, z-order, version, changed_at.
10. Page: stack of `<img>` per layer inside one transformed canvas; layer
    panel with checkboxes, presets, opacity; per-layer preload-and-swap.
11. Extend the test: board lists F.Cu/B.Cu/Edge.Cuts with colours, a layer
    SVG is served, editing one layer's content bumps only that layer.
12. Repo: `git init`, `.gitignore`, README with screenshots, docs index,
    `CLAUDE.md` for agents working on it; first commit, no remote.
